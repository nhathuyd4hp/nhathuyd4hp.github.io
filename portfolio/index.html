Internal · ASTR Ltd

Internal RPA Platform

Schedules, dispatches and monitors automation workflows. Its bots collect data, submit forms, distribute documents and generate reports across the company's enterprise platforms.

  • Distributed orchestration with FastAPI, Celery and Redis to schedule, dispatch and monitor workflows.
  • Webhook endpoints so external systems can trigger workflow runs.
  • Real-time channel over WebSockets and Redis Pub/Sub that streams live logs, execution events and decision prompts to clients.
  • Waiting on user decisions: a worker that needs an answer blocks on a Redis BLPOP until the user responds through a REST API, without polling.
  • Locking to prevent race conditions between concurrent workers.
  • Scheduling and persistence with APScheduler on MySQL, plus S3 storage for result files with lifecycle expiry; S3 event notifications keep the metadata in MySQL up to date.
  • Workflow modules in Playwright, Selenium and Google Apps Script for data collection, form submission, document distribution and report generation.

Internal · ASTR Ltd

Internal Document Management Platform

Brings company documents from SharePoint, Google Drive and S3 into one place to browse, search, edit and move, without changing where the files live.

  • One place for company documents across SharePoint, Google Drive and S3: browse, search, upload, and copy or move between sources.
  • Storage provider abstraction over Microsoft Graph, Google Drive API and boto3, so every feature shares one code path wherever a file lives.
  • In-browser editing of Word, Excel and PowerPoint through ONLYOFFICE Docs, saved back to the source with ETag-based conflict detection.
  • Access and security with role-based access, JWT sessions with rotating refresh tokens, and encrypted storage credentials.
